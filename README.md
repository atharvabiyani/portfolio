# 🧑‍💻 Atharva Biyani — Developer Portfolio

Welcome to the source code for my personal software engineering portfolio, built to showcase my skills, experience, projects, and writing. - **Hosting:** Vercel
- **Deployment:** GitHub Actions (via Vercel CI/CD)

## 📂 Features

- Clean, minimalist UI with responsive design
- Smooth scrolling and intuitive navigation
- Dynamic content: education, experience, projects, and blog articles
- Profile image, tech stack badges, and hobbies section
- GitHub, LinkedIn, Medium, and email contact integration
